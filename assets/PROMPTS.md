# スプライト画像の生成プロンプト（ChatGPT 用）

生成した画像を **この `assets` フォルダに下記のファイル名で保存** → ページを再読み込みすると自動で反映されます。
画像が無いものは CSS 描画のままなので、1枚ずつ差し替えても動きます。

| ファイル名 | 内容 | サイズ | 背景 |
|---|---|---|---|
| `machine.png` | マシン本体（ハンドル無し・ドームは空） | 1024×1536（縦） | 透過 |
| `knob.png` | 回転ハンドル | 1024×1024 | 透過 |
| `capsules.png` | カプセル16色のスプライトシート（4×4） | 1024×1024 | 透過 |
| `bg.png` | 背景（任意） | 1536×1024（横） | 不透過 |
| `burst.png` | 当選時の後光（任意） | 1024×1024 | 透過 |

## コツ

- **同じチャットで ①→⑤ の順に続けて** 生成すると絵柄が揃います。
- 透過にならなかったら「背景を完全に透過したPNGで出し直して」と追加で頼んでください。
- ①でハンドルが描かれてしまったら「ハンドルを消して、平らな丸い台座だけにして」と修正依頼。
- ③でマス目がずれたら「16個すべてを同じ大きさで、4×4の等間隔グリッドの各マス中央に配置し直して」と修正依頼。
- 位置が合わないときは、アプリの **設定タブ →「位置合わせ」** のスライダーでドーム／ハンドル／取り出し口を画像に合わせられます（列数・行数も変更可）。

## ① machine.png（最初にこれ）

```
ゲーム用のスプライト素材を作ってください。

【題材】日本のカプセルトイ（ガチャガチャ）マシン本体を、真正面から見た1台。
【画風】超リッチで豪華なゲームUIイラスト。光沢のある3Dレンダリング風、ツヤツヤのキャンディ塗装、
金の縁取りと宝石の装飾、柔らかいスタジオライティング、くっきりした輪郭、高精細。
【配色】本体は深い赤〜マゼンタ、装飾はゴールド。

【構図の厳守事項】
- 画像サイズは縦長 1024×1536。背景は完全な透過（透明）PNG。
- マシンは左右対称で、画像の中央に全体が収まる（上下左右に少し余白）。パースなしの完全な正面図。
- 上半分：大きな「真円の透明ガラス球ドーム」。中心は画像の横50%・上から30%の位置、直径は画像幅の約74%。
  ドームの中は【完全に空】にする（カプセルは1個も描かない）。ガラスの内側は暗めの単色で、中が見やすいように。
- 中央下（横50%・上から68%の位置）：ハンドルを取り付けるための「平らな丸い金属の台座」だけを描く。
  【ハンドル・つまみ自体は描かない】（別画像で重ねます）。
- 下部（横50%・上から88%の位置）：カプセルの取り出し口（暗い開口部）。中にカプセルは描かない。
- 文字・ロゴ・数字・透かしは一切入れない。床の影も描かない。
```

## ② knob.png

```
さっきのガチャマシンと同じ画風・同じ質感・同じライティングで、マシンに取り付ける「回転ハンドル（つまみ）」だけを描いてください。

- 画像サイズ 1024×1024、背景は完全な透過PNG。
- 真正面から見た図。丸い白〜銀のダイヤルの中央に、横向きの金色のつまみバーが付いたデザイン。
- ハンドルは画像の中心にぴったり配置し、画像幅の約90%の大きさ。回転させて使うので、外形は真円にする。
- 影・文字・背景の装飾は描かない。ハンドル以外は何も描かない。
```

## ③ capsules.png（スプライトシート）

```
さっきのガチャマシンと同じ画風・同じ質感で、カプセルトイの「カプセル」のスプライトシートを作ってください。

- 画像サイズ 1024×1024、背景は完全な透過PNG。
- 4列×4行の等間隔グリッド（1マス 256×256）に、カプセルを1マスに1個ずつ、合計16個。
- 16個はすべて【同じ形・同じ大きさ・同じ向き】で、色だけが違う。
  色：赤、オレンジ、黄、黄緑、緑、ミント、水色、青、紺、紫、ピンク、マゼンタ、金、銀、白、虹色。
- カプセルは真円の球体。上半分が不透明で光沢のある色付き、下半分が半透明のクリア、
  合わせ目（継ぎ目）は【ちょうど真ん中を水平に】通る。
- 各カプセルはマスの中央にぴったり配置し、マスの幅の約80%の直径。隣のマスにはみ出さない。
- グリッド線・枠線・影・文字・数字は一切描かない。
```

## ④ bg.png（任意）

```
さっきのガチャマシンに合う背景イラストを描いてください。

- 画像サイズ 横長 1536×1024。透過ではなく通常の画像。
- 夜のきらびやかなゲームセンター／お祭りの雰囲気。ネオン、ボケた光の玉、紙吹雪、深い紫〜紺のグラデーション。
- 中央にマシンを重ねるので、【中央は暗めで何も置かず】、にぎやかな要素は左右と上下の端に寄せる。
- 全体をやや暗く、ピントをぼかし気味にして、手前の物が目立つように。
- マシン・人物・文字・ロゴは描かない。
```

## ⑤ burst.png（任意）

```
さっきのガチャマシンと同じ画風で、大当たり演出用の「後光エフェクト」を描いてください。

- 画像サイズ 1024×1024、背景は完全な透過PNG。
- 画像の中心から全方向に放射状に伸びる金色の光線（集中線）と、きらめく星・光の粒。
- 回転させて使うので、【中心点に対して対称な円形】にし、外側に向かって透明に溶けていく。
- 中央には文字を重ねるので、中心部は明るい白金色のやわらかい光だけにする。
- 文字・物体・枠は描かない。
```
